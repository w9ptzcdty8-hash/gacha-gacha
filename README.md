# ガチャガチャ

MRS TOOLSのボタン式カプセル抽選ツール。HTML / CSS / JavaScriptだけで動作し、ビルドや外部ライブラリは不要です。

共通UI・オフライン処理は [MRS-TOOLS-TEMPLATE](https://github.com/MRS-TOOLS/MRS-TOOLS-TEMPLATE) をベースにし、タイトル・MRS TOOLSリンク・広告帯は [世界時差時計](https://github.com/MRS-TOOLS/world-time-clock) を参考にしています。

## 使い方

1. 「賞の設定」で賞名・カプセルの色・個数を設定します。
2. 「まわす」を押すと、つまみが回転し、カプセルが出て開き、結果を表示します。
3. 出たカプセルを減らして、残っているカプセルから次の抽選を行います。
4. 「カプセルを元に戻す」で、設定した個数に戻し、履歴を消せます。

最大20種類、各0〜9,999個、合計1個以上。初期設定は1等1個・2等3個・3等6個・参加賞20個です。
残っているカプセル1個あたりの確率が等しくなるよう、Web Cryptoの乱数を使用します。
履歴は最新200件まで保持し、抽選回数は全件を数えます。
設定を変更して保存する場合は、確認後に残数・履歴をリセットします。変更せず保存した場合は履歴・残数を維持します。
動きを減らす設定では、演出を短縮します。

## 保存

設定・残数・履歴は端末内のlocalStorageキー `mrs-gacha-gacha-v1` に保存します。
抽選データはサーバーに送信しません。ガラガラポンの保存データは引き継ぎません。
ブラウザのデータ削除やプライベートブラウズでは、保存データが消える場合があります。
保存に失敗しても画面上では使用でき、失敗したことを表示します。

結果はアニメーション開始前に保存するため、途中で再読み込みしてもカプセルは戻りません。
別タブの保存を検知したら操作を停止して再読み込みを案内します。同時利用の厳密な排他制御はありません。抽選には1つのタブを使用してください。

## オフライン・広告

HTTPSまたはlocalhostで一度アクセスし、Service Workerの準備が完了すると、オフラインでも起動・抽選・設定変更・保存・履歴表示ができます。
キャッシュ対象はアプリ本体のみ。外部広告・外部リンクはオンライン時のみ利用できます。
広告タグは世界時差時計と同じadmaxタグを使用しています。アプリのスクリプトは広告より前に実行します。
PWA用manifest・アイコン・インストール導線は含みません。

## ローカル確認・公開

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。
Cloudflare Pagesはルートの静的ファイルを配信してください。Cloudflare設定を自動変更する処理はありません。

## 更新時

CSS / JSの `?v=1` を変更するときは、Service Workerのキャッシュ対象とバージョンを合わせて更新します。
旧キャッシュを削除する範囲は `mrs-gacha-gacha-` で始まるものだけです。

## 確認項目

抽選・連打防止・残数ゼロ・設定追加/削除/保存・リセット取消・再読み込み・保存失敗・オフライン起動・スマートフォンの縦横表示。
iPhone実機・実際の広告配信・Cloudflare本番は、公開後に確認してください。
